# LyrixMatch-App

자연어 처리를 이용한 노래 가사 단어 기반 제목 맞추기 퀴즈 어플

---

## 🎵 프로젝트 개요

**가사 요약·분석 기반 노래 제목 퀴즈 앱**으로, “클라이언트(Flutter) – 서버(Flask)” 구조를 따릅니다.

사용자는 음악 스트리밍 플랫폼인 스포티파이(Spotify)에서 자신이 생성한 플레이리스트의 URL을 입력합니다. 백엔드 서버는 실시간으로 가사를 수집하고 자연어 처리(NLP) 파이프라인을 통해 **요약문, 주요 키워드, 워드클라우드 이미지**를 분석하여 제공합니다. 사용자는 이를 보고 노래 제목을 맞추는 퀴즈를 풀게 됩니다.

---

## 🤔 개발 동기

숏폼 플랫폼(TikTok, Instagram Reels 등)의 확산으로 노래가 짧은 구절 형태로 재생산되고 있습니다. 실제로 2024년 상반기 걸그룹 음원 상위 400곡 기준, 영어 가사 비율이 41.3%에 달하며 이는 계속 증가하는 추세입니다. 이로 인해 국내 음원 청취자들의 가사 번역 및 해석에 대한 수요 역시 꾸준히 증가하고 있습니다.

이러한 배경 속에서 단순히 가사를 찾아 번역하는 것을 넘어, **가사 전체를 요약한 문장과 핵심 키워드를 통해 노래를 유추해보는 경험**은 음악 청취자들에게 색다른 재미를 줄 것이라고 생각했습니다.

본 프로젝트는 기존 음악 퀴즈와 차별화된 방식으로, **자연어 처리(NLP) 기술을 활용**하여 ‘가사-제목 추론형’ 퀴즈 서비스를 제공하고자 합니다.

## 🛠️ 프로젝트 진행계획

### 적용 기술

#### 🖥️ 서버 기술 스택
- **Python 기반 Flask 서버**
- **Cloud Run**을 이용한 컨테이너 배포

#### 🧠 사전학습모델 (Pre-trained Models)
- **영어:** HuggingFace Transformers - `facebook/bart-large-cnn` (BART)
- **한국어:** `t5-base-korean-summarization`

#### 📝 텍스트 분석
- **영어:** NLTK 기반 문장 분리, 불용어 제거, 토큰화
- **한국어:** KoNLPy 형태소 분석 (명사 추출 등)

#### 📱 클라이언트 (Flutter) 기술 스택
- **Flutter (Dart)**
- **REST API 통신** (http 패키지 등)
